!2 Summary

This test validates:
- ✓ User can be assigned to multiple tenants with different roles
- ✓ User authenticates and gets context for their primary tenant
- ✓ TENANT_ADMIN can access their own tenant
- ✓ User cannot access other tenants they're assigned to via different role
- ✓ Multi-tenant user management works correctly

Note: JWT contains the user's primary tenant context. Switching tenant context would require re-authentication or a tenant-switching API endpoint (not yet implemented).
