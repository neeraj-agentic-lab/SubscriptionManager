!2 Getting Started

To run tests:
 1. Ensure the Subscription API is running on http://localhost:8080
 2. Ensure PostgreSQL database is accessible
 3. Click on a test suite above (AdminScenarios or CustomerScenarios)
 4. Click the "Suite" button to run all tests in the suite
 5. Or click individual test pages to run specific tests

!2 Configuration

Base API URL: http://localhost:8080
FitNesse Port: 9090
Test System: Slim
Fixtures: RestApiFixture (REST API client)

!2 Key Features Tested

**Admin Capabilities:**
- Tenant onboarding and isolation
- User management and bulk operations
- Subscription lifecycle (create, pause, resume, cancel, modify)
- Subscription history and audit trails
- Delivery management and cancellation
- Webhook management for integrations
- API client lifecycle management
- Multi-tenant user workflows

**Customer Capabilities:**
- Browse available plans (public endpoint)
- Self-signup and subscription creation
- View subscription dashboard
- Manage subscriptions (pause, resume, cancel)
- View and manage deliveries
